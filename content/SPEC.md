## 交付檔案 1：文字教材 `content/text/chNN.md`
- 第一行 `# 第N章　章名`（與章節表一致），下一行一段 `> 學習目標：` 列 3–5 點。
- 內容深度：要比實體簡報**詳細很多**，目標每章約 5,000–9,000 中文字（稽核、案例章可更長）。用 `##`、`###` 分節，善用表格。
- 條文章節的每個條款建議結構：
  1. `### 條文要求`：重點摘述（可短引原文，用「」標示，勿整段大量照抄）
  2. `### 白話解說`
  3. `### 實務作法 / 建議產出文件`
  4. `### 管理案例`（虛擬案例）
  5. `### 稽核重點`：稽核員會問的問題（列 3–6 個）、要看的證據、常見缺失
- 可用的特殊區塊（用 blockquote，第一行粗體標籤）：
  - `> **💡 Allan 講師說：** ……`（顧問/稽核經驗談）
  - `> **🎀 阿拉蕾發問：** ……` 接著 `> **Allan：** ……`
  - `> **⚠️ 常見誤區：** ……`
  - `> **🔍 稽核員視角：** ……`
- 章末 `## 本章重點回顧`（條列），再 `## 自我檢測`：3–5 題，每題格式：
```
<details><summary>Q1. 題目文字？</summary>

**答案：** …… 解析……
</details>
```
- 繁體中文（台灣用語：資訊、軟體、資料、品質、網路、伺服器、專案、文件），語氣專業但親切。

## 交付檔案 2：互動影音腳本 `content/video/chNN.json`

```json
{
  "id": "ch04",
  "title": "第4章　…",
  "scenes": [
    {"type": "slide", "title": "畫面標題", "bullets": ["要點1", "要點2", "要點3"],
     "lines": [ {"s": "R", "t": "阿拉蕾的台詞"}, {"s": "A", "t": "Allan 的台詞"} ]},
    {"type": "quiz", "title": "隨堂小挑戰", "q": "題目？", "options": ["A選項", "B選項", "C選項"], "answer": 1,
     "explain": "答對/答錯後顯示的解析",
     "lines": [ {"s": "R", "t": "出題前的台詞"} ],
     "after": [ {"s": "A", "t": "公布解析的台詞"} ]}
  ]
}
```
- `s`：`"A"`=Allan、`"R"`=阿拉蕾。`answer` 為 0 起算索引。
- 每章 8–14 個 scene，總台詞約 40–70 句；每章至少 2 個 quiz scene（互動檢核點）。
- **每句台詞 15–70 個中文字**（短句＝每段語音小、載入快）。長說明拆成多句。
- 第一個 scene 開場要短而有趣（阿拉蕾先開口），讓學員立刻進入；最後一個 scene 收尾＋預告下一章。
- 台詞是口語：活潑、生動、有梗、台灣口吻（「欸」、「啦」、「喔」、「對吧」、「齁」適量）。Allan 常用稽核現場故事、顧問經驗舉例；阿拉蕾負責提問、比喻、吐槽、整理重點。
- 台詞中**不要用**表情符號、括號註解、網址、全形破折號以外的特殊符號；英文縮寫可（AI、SoA、PDCA）。條文編號直接寫「6.1.2」「A.6.2.4」，程式會轉成口語念法。
- bullets 每點 ≤ 26 字，每 scene 2–5 點。
- 必須是合法 JSON（UTF-8，雙引號，無尾逗號）。寫完用 `python3 -c "import json;json.load(open('檔案'))"` 驗證。
